The fine print

Honest details.

Everything stays local
Audio is downloaded and separated on your machine. No accounts, no cloud, no telemetry.
First run is the big one
Setup installs a private Python engine, about 2GB, one time. After that, songs split in minutes and work offline.
Requirements
macOS 12+ (Apple Silicon) or Windows 10/11, with Python 3.9+ available. ffmpeg is bundled.
Open source, MIT
Source code is on GitHub. Powered by demucs, yt-dlp and the Web Audio API.
